# Birthday Wishes for Deekshi

A standalone, static birthday greeting site for Deekshi, affectionately called Nana, inspired by the supplied reference video. It lives entirely in `birthday-wishes/` so it does not change the portfolio under `docs/`.

## Run locally

Open `index.html` directly, or serve this folder with any static HTTP server. No build step or package install is required.

## Passcode

The demo passcode is **1224**. The check is implemented in front-end JavaScript, so it is a playful reveal rather than secure authentication.

## Contents

- `index.html` — accessible screen and dialog markup
- `styles.css` — responsive pink, cream, and plum visual system
- `app.js` — screen flow, keypad, gallery, and interactive cake
- `assets/` — original generated character and scrapbook illustrations

## Scope

This branch adds only this folder. It does not edit, merge, or deploy the QA portfolio. The site is intended to be hosted from a separate public repository so it has its own GitHub Pages URL and does not affect the portfolio.
