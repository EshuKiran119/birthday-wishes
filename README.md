# Birthday Wishes — Deekshitha Reddy (Nana)

A standalone static birthday website made with HTML, CSS, and JavaScript. GitHub Pages serves the files directly from the `main` branch root; there is no build step or backend.

## Passcode

The playful reveal uses **1224**. It is checked in client-side JavaScript, so it is not secure authentication and must not be used to protect private content.

## Run locally

From this directory, run `python3 -m http.server 8000` and open `http://localhost:8000/`.
